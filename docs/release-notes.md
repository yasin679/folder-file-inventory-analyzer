# Release Notes v1.2

## 1 Release summary

| Item | Value |
|---|---|
| Product | Inventory Analyzer (Folder and File Inventory Analyzer) |
| Version | 1.2 |
| Release date | 24-Oct-2026 |
| Status | Ready for UAT |
| Source | https://github.com/yasin679/folder-file-inventory-analyzer |
| Platform | Any current browser; Microsoft Edge or Google Chrome for every feature. Windows desktop launcher included. |

Inventory Analyzer lists every file and folder inside a folder you choose, shows how many files each folder holds and where each file is, analyzes what uses the space, and exports Excel and CSV reports. It runs entirely in the browser: nothing is installed, nothing is uploaded, and files are only read, never changed.

Version 1.2 lets you **go back to any recent scan and download its reports again**, even after closing the app, and carries its complete documentation set inside the app.

## 2 New in v1.2

### 2.1 Reopen past scans

- **Open** any of the newest 20 saved scans from **Scan History**. Every screen, the Folder Explorer and every download work as if the scan had just run. Reopened scans are labelled **Saved scan**.
- **Excel** and **CSVs** buttons on every history row download that scan's reports without opening it.
- **Open last scan** is offered on New Scan when the app starts.
- The history table was redesigned: full folder names, scan ID, start and end times, duration, and buttons that are no longer cut off.
- New setting **Keep full results of past scans on this PC** (on by default). Turn it off to keep only a summary of each scan.
- Deleting a scan also deletes its saved results. Older scans keep their summary row and show **Summary only**.

### 2.2 Documentation

- A full set of seven guides, each with a document ID, as Markdown (readable on GitHub) and as a formatted PDF with cover, document control, contents and page numbers:

- Screenshots and PDFs are generated by scripts in `docs/build/`, so they can be refreshed for every release.

## 8 Known issues and limitations

| # | Item | Workaround or plan |
|---|---|---|
| 1 | Upload mode cannot see empty folders | Use Edge or Chrome with **Choose folder…** |
| 2 | The shared link's hosting page may block the folder picker | Use **Upload a folder…**, or the desktop launcher |
| 3 | The whole inventory is held in memory; a few hundred thousand files is the practical limit on a typical laptop | Scan large trees in parts; streaming to storage is on the roadmap |
| 4 | Browsers expose only last-modified dates, no full paths, no created or accessed dates, no hidden attribute | By design; nothing is guessed |
| 5 | Sizes are logical file sizes, not space used on disk | Compare with Explorer's **Size**, not "Size on disk" |
| 6 | Duplicate hashing reads each candidate file whole; files above the hashing limit are unverified | Raise the limit in Settings when needed |
| 7 | Each way of opening the app keeps its own history; browsers may clear it | Keep the Excel reports you need |
| 8 | End-to-end tests run in Chromium only; the native folder picker was tested with a stand-in | Run the UAT cases (IA-UAT-06) in your browsers |

## 9 Installation notes

- New installation: follow the Installation and Administration Guide (IA-IG-02). On Windows, copy two files and double-click the launcher.
- Upgrade: replace `Inventory Analyzer.html`. History and settings are kept.
- Shared link: the owner must set **Share > Anyone with the link** before others can open it.
